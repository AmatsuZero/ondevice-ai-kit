# Optional fixed Apple MLXVLM Demo host design

Goal: connect the existing single-image shared Demo host to the already verified fixed Apple model/ModelStore, without adding a backend to default Demo or Android. This is a separate package after picker1ece99d, not real-device lifecycle acceptance.

The base iOS15/macOS12/API26 graph stays unchanged. Only a fresh generated enhanced Demo with ODAI_MULTIMODAL_MLX_DEMO=1 (requires ODAI_MULTIMODAL_DEMO=1 and ODAI_VIDEO_DEMO=1) links local apple-mlx/ODAIKitAppleMLXVLM and base ModelStore, targets iOS18, uses its own bundle io.ondeviceai.multimodalmlxdemo and copies the exact existing apple-mlx/Package.resolved. No downloads or package updates. Default generated and protected original projects remain untouched.

Runtime additionally requires explicit launch argument --multimodal-mlx-local-model. Otherwise the current unavailable host remains. The enhanced path uses only Documents/model as source, canonical SmolVLM2Model manifest and existing fixed revisions (model fa57db46815177fbdfd65cc85a2b3416a8332268, MLXVLM6e338e5df49424fc0db7c6d58184d622f92ed18a), its own Documents/multimodal-model-store install root and fresh temporary input store. ModelStore verifies all assets before acquire; MLXVLMBackend takes lease ownership; IOSMultimodalBridge takes native client ownership; existing MultimodalHost/VM remain generation/lifecycle owners. No raw model or image path enters shared requests.

One small MainActor factory composes install/acquire/backend/client/bridge/input host. An injected backend builder supports tiny real ModelStore lease tests; production only passes canonical MLXVLMBackend. Every throw/cancel boundary releases whichever lease/backend/client has been acquired; failed preparation leaves the original unavailable host. The installed verified model may remain for explicit reuse; closing host releases the active lease through existing bridge/client drain. It does not recursively delete model roots.

DemoController prepares once asynchronously only for the explicit launch argument, shows a short preparation state before constructing shared controls, and publishes the replacement host on success. Preparation task captures controller weakly across awaits, cancels on owner release; late completion closes its host instead of leaking. A host completed while inactive is immediately backgrounded; foreground never restarts preparation or generation. On failure show generic preparation failure and retain unavailable. Picker is shared only within the same controller; old unavailable host closes before replacement. No model download button, arbitrary model chooser, auto generation or synthetic success.

Tests: real tiny ModelStore install/hash/lease/remove plus existing IOS bridge/VM confirm transfer/close, builder failure, invalid client registration, pre/post-acquire cancellation, integrity failure before backend creation. Generator tests inspect actual enhanced product/source/flags/target/lock/bundle/default dependency isolation and reject partial flag sets before output mutation. Enhanced device-target compile uses only the existing matching SourcePackages cache with automatic resolution/package updates disabled. Actual iOS touch UI, KMP→real runtime device lifecycle, natural quality/GPU/energy/minimumOS stay unverified; next independent device package covers success/update cancel/drain/reentry/background/close/lease/closed rejection.

Only local commits; preserve dirty/untracked protected hashes, .superpowers/artifacts/logs. No downloads, private media, audio, signing asset changes or subagents. Existing Video/P6/ASR/review gaps and5/12 complete/P9active remain.
