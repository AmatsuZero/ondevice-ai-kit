# Single-image Demo picker and shared action design

Package after native host 29458bb. Add explicit shared action callbacks for selecting/clearing input and wire Android Activity GetContent to a host-owned temporary local copy. Existing VM/host/store remain the only ownership layers. Default unavailable remains explicit; no model/client factory, picker result is not inference evidence, and no iOS protected project file is changed.

Shared `MultimodalDemoActions` exposes `selectImageFile()` and `clearImageFile()`. `MultimodalScreen` renders optional select/clear controls and only invokes callbacks; host model state remains source of truth. Android `MainActivity` owns one picker registration, copies a returned content URI to a unique cache file, invokes `MultimodalHost` once, then deletes the staging file. Activity onStart/onStop forwards host foreground/background with preservePicker for an in-flight picker; onDestroy closes host exactly once. No URI/path enters the bridge request.

Use an opt-in Android Intent extra `odai.multimodal.enabled`; default false leaves old Activity UI unchanged. Content copies are capped at32MiB, dispatched on IO, local staging removed in finally, cancelled/failed copy does not expose a path in UI diagnostics. No broad storage permission. Late background/leave/close host ticket filtering is retained.

iOS uses UIDocumentPicker for PNG/JPEG, MainActor callbacks into existing host/store. Extend only the independent generated Speech+Video Demo with ODAI_MULTIMODAL_DEMO opt-in; default generated/checked-in projects stay unchanged. Add a new dedicated iOS controller entry with actions instead of changing old controller labels. DemoController owns new optional host under the compile flag and forwards lifecycle/close. Independent generated project source/product assertions and actual compile prove this wiring while the protected project stays untouched.

Tests: actual Compose instrumentation clicks action controls and invalidates a late selection on page leave; Android actual opt-in Activity launches system GetContent and cancels without reading media, synthetic content is copied with explicit fixture-only evidence. Unit stream tests prove cap/errors/staging cleanup. Host tests are rerun. Shared tests, both Kotlin Native frameworks/header and old Swift labels compile; new iOS picker delegate tests and generated full app build run on simulator. Real iOS UI/system picker roundtrip remains unverified unless executed. No reuse of prior Video automation-initialization timeout as a new failure. Default unavailable/closed errors remain typed, no generated-success path is added to production.
