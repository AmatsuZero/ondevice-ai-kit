# Apple OpenCV Identity prototype

Continue the functionality-first roadmap by reusing the already approved OpenCV 4.12.0/YuNet/SFace runtime/models and the same separately approved NASA astronaut sample for local flow testing. No new biometric data, calibration, redistribution or production use is inferred. Apple backend has its own embedding-space backend ID; no cross-platform equivalence is claimed.

Agent implementation choice: a separate optional `apple-opencv` Swift package, with a small Objective-C++ native target and Swift `ODAIKitOpenCVIdentity` product. The default `apple` package remains free of OpenCV. Stage the hash-verified official iOS SDK under ignored local artifacts/vendor paths; retain upstream notices. Prefer official packaged SDK to rebuilding OpenCV; do not introduce another inference runtime or convert model weights. Exact platform slices/minimum OS are verified from the artifact before integration.

Native CPU processing mirrors the Android bounded profile: upright encoded image, <=10MiB, each axis 16...4096 and <=4194304 pixels; ignore EXIF, resize long edge to <=640 (linear), YuNet score .9/NMS .3/top5000; exactly one geometrically usable face for embedding, official alignCrop 112x112 and SFace float32 128 features with explicit L2 normalization. Binary geometry is not calibrated quality. Policies stay UNVERIFIED; no fake 1:1/1:N acceptance or PAD.

Swift factory validates an exact fixed ModelManifest and runtime version, initializes while a model lease is held, then returns the existing LocalIdentityBackend owning its own lease. Native calls serialize; close rejects new work, joins in-flight synchronous DNN work and frees C++ smart pointers. Stop is cooperative between blocking native stages; no fast native cancel is promised. All exceptions map to stable Identity errors and sanitized stage/category diagnostics, with no image/vector/path/raw native exception logging.

Deliverable includes optional model/backend code, real-model native probe/consumer and iOS Demo session wiring using existing IOSIdentityBridge/IdentityViewModel. Keep explicit local enrollment consent, app-private encrypted storage, full-grant teardown, opaque probe refs and model release. Use isolated generated Xcode output; never edit the protected Demo pbxproj. Actual touch/picker acceptance is distinct from headless real-model flow.

Verification: RED before new backend symbols, targeted tests for bounds/normalization/policy/model identity/stop/lifecycle; real approved image must produce one face/aligned normalized 128-vector and encrypted enrollment/deletion; blank/malformed and unverified policy fail explicitly; model lease pins then releases. Device/simulator evidence must name runtime/APK(or app)/model/input identities. Default Apple suite and optional build pass; any unavailable real-device/UI/review gate remains explicit. Preserve nine protected files, no push/merge/release, corner/resource work deferred.
