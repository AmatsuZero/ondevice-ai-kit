# W9：离线录音与文件效果变声

更新：2026-11-17。状态：**W9-0 原型可行性已接受 / SDK与Demo待实现**。本周新增工作包；不作为 W3 完成条件，也不依赖 Qwen/Whisper 质量改进。

## 交付合同

以[本周范围设计](../superpowers/specs/2026-11-17-weekly-delivery-voice-effects-design.md)为准：原声/高音/低音，前台录音或文件导入，结束后离线处理，双端 SDK + KMP Demo，原声与结果试听、WAV 导出。首版不做实时监听、通话变声或 AI 音色克隆。

30秒、单声道PCM16 WAV、16/44.1/48kHz、±4半音与精确帧数已由原型验证并写入[实施合同](../voice-effects/contract-v1.md)。四环境各74项通过，见[验收报告](../validation/w9-minimal-chain-20261117.md)；工程烟测不是人声质量或产品资源预算接受。最终独立复核429无结论。

## 可复用与必须新增

| 范围 | 处理 |
| --- | --- |
| 文件 lease、权限状态、音频会话、busy/取消/drain/close | 遵循既有 Speech/Video 模式，不能假定现有 ASR 采集器已能输出完整录音 |

| 第三方变声库 | 当前未选定、未授权新增；先证明现有执行面可行，再作依赖决定 |

## 完成标准

- [x] 两端原型真实文件渲染可行性：有效PCM16 WAV、频率/帧数检查通过；实际硬件播放及听感未验。
- [x] 工程合同冻结（主代理；最终独立复核待补）：格式/上限、预设、错误、输出所有权、取消/关闭与线程语义一致。
- [ ] 无麦克风权限时，导入→转换→试听→导出仍可用；录音拒权、取消、上限自动停止可正确退出。
- [ ] 双端原生 SDK 和独立消费者编译通过；KMP bridge/Demo 的实际调用与后端绑定通过。
- [ ] 原声/高音/低音输出有效；空/坏/超限输入拒绝；失败、取消、close 不留已发布半成品、不改变输入。
- [ ] 长音频中活动取消、立即重入/busy、关闭、前后台/中断、重复使用与资源恢复有目标设备证据。
- [ ] 实际候选的时延/采样内存/适用资源与预算结论、可懂度/失真听验和实际导出回读已记录。
- [ ] 同一候选的通知/消费/独立复审通过；延期和未测项明确列出。本周阶段交付仍由总表决定，不由本页勾选自动发布。
