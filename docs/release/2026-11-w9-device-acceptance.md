## 开始前固定身份

记录源码commit及未提交增量摘要、冻结合同SHA、所有构建flag/依赖版本、包hash、设备型号/系统与安装身份。先确认目标设备及普通App保护记录，再决定隔离安装标识和签名；未获本轮签名/设备操作授权时只准备候选，不沿用历史单次授权。最低系统未测则明确留空。

建议先做文件流程，再由用户在场开始录音。留存新合成1秒220Hz WAV作为工程输入及一段授权人声作为听感输入；记录hash，原文件只读。系统权限测试与文件流程分别记录，不以授予麦克风作为文件转换的前提。

## 核心流程与失败路径

| 操作 | 应观察的结果 | 留存证据 |
| --- | --- | --- |
| 无麦克风权限进入页面，导入合规WAV | 无自动开麦；未给录音权限也可导入 | 权限状态、页面、输入hash |
| 依次原声/高音/低音转换 | 单次终态；相同采样率/帧数，原声独立且字节相同 | 三输出结构、backendId、非空文件及输入不变 |
| 原声与结果试听，然后导出并回读 | 无崩溃/悬挂；输出读完才释放，导出文件可解析且与所选输出一致 | 授权人声听感记录、导出hash/格式/帧数 |
| 重选后取消；导入坏/空/双声道/超30秒文件 | 保留之前输入；明确失败，不截断或留下已发布半成品 | 错误类别、旧输入/输出保持、目录清理 |
| 转换中取消、立即重入、close/离页 | 等待实际drain/输入释放；忙时不并发、不交付迟到输出 | 状态序列、输出所有权与清理、可再次进入 |
| 播放/转换/录音时切后台或系统音频中断 | 停硬件/取消处理，恢复后状态可用；既有Speech/TTS不争用 | 音频会话/资源观察，原App恢复 |
| 用户点击录音→拒权，再明确授权→录音/停止 | 拒权可退出且文件导入仍可用；成功录音走同一转换入口 | 权限与按钮状态、录音格式，无未经点击采集 |
| 用户明确开始30秒录音并等待上限 | 自动停止并释放会话；文件≤30秒，无静默裁剪外部文件 | 帧数/时长、终态与资源恢复 |
| 导出取消/失败、反复清理与离页 | 未读完不删输出；失败可见，未知reference不能误删文件 | 输出引用/文件、失败与恢复结果 |

## 资源与验收裁定

固定同一输入与同一候选分别记录处理wall time、实际采样范围内的内存、音频资源/会话恢复和重复使用情况。采样最大值不宣称真实峰值；Swift服务/系统开销与App内存分别说明。没有批准预算时记“已测/待裁定”，不能借旧ASR实验的1.5GiB停止线当W9产品预算。

记录人声可懂度、音高可感知变化、失真/首尾缺损及主观接受人；合成频率正确不能替代人声听验。运行结束验证独立候选输出清理、普通App/模型保持和设备恢复，再交同候选独立复审。所有缺测、失败和首错保留；不按目标日期自动通过。
