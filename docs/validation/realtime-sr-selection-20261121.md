# 播放中切换超分后端：SDK 接入验收（2026-11-21）

本次只验证 SDK 选择与呈现。Android 播放器通过公开的 `RealtimeVideoSR` 切换；接入方仍可不开放增强。[接入示例](../../kmp-binding/REALTIME-SR.md) · [精简证据（JSON、可复算的逐帧 CSV）](realtime-sr-selection-20261121.zip)。

**播放未暂停。** TECNO KM9（Android 15 / API 35）持续播放同一段 960×540、30 fps 视频，依次点击五种选择（首尾为原画）。按切换代次、循环、源帧序号、EGL 帧 ID 匹配提交与正显示时间。下表为退出前日志中已确认上屏的帧；未匹配帧不参与计数。这是一次功能短测，不是实时达标率、画质排名或跨机型评估。

|---|---|---|
| 原画 | ORIGINAL | 104 帧原画 |

**暂停在同一帧。** KM9 上第 63 帧（2.100 秒），顺序为原画 → Spatial → CuNNy → 原画。四次提交均匹配到实际显示时间。1080×1919 的播放器表面上，相对首次原画，Spatial 改变 55,030 个 RGB 像素，CuNNy 改变 61,848 个；切回原画的差异是 **0**。随后恢复播放、拖动进度、切后台再回来都通过。API 36 软件模拟器在修正旧开关和调试页退出逻辑前也通过同帧像素及恢复测试，但没有可匹配的显示时间；不据此推断硬件性能。

**构建和边界。** 最终 Android AAR 包含公共控制器、可选宿主接口和 Android 适配器；41 项单测通过，Demo、测试 APK 构建成功，Lint 0 错误、11 警告。兼容开关在无渲染器或未允许 Auto 时保持原画。修复了调试页退出后迟到回调写入已关闭日志的问题：最终包同一流程按返回退出，进程仍存活且无致命异常。iOS Release KMP framework 构建通过，Swift 桥接针对真实 UHPlayerSDK 功能分支 `7d40dfe` 的模块、arm64 iOS 15.1 通过类型检查；本轮未重做 iPhone 设备验收。API 26 是 Android 模块的最低声明，本轮未测 API 26 真机。
