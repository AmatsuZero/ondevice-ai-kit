# F08：补齐同八帧物品展示后，Qwen3 仍把五种物品回答成三种

2026-11-14。结论：`video_9676` 的旧均匀八帧确有展示漏采；补入两杯、三笔的可见展示后，两个独立控制都仍输出 **C（3）**，正确标签 **B（5）**。漏采不足以单独解释本题错误。当前模型/输入配置下的细粒度身份区分、跨帧去重或计数链路仍不可靠；本实验不能区分这些内部环节，也不证明所有模型都做不到视频理解。F08/W6 **open/not-ready**。

`0, 2.986758703083, 8.993462317061, 14.734672685428, 19.579862609100, 23.993628248100, 28.971559419905, 32.489297447981`。
