# W3 bounded terminal collection (2026-11-13)

`terminal_device_collect.collect(root, ctx, *, serial)` preserves two fresh bounded
report reads and binds their exact bytes/SHA to the existing observed terminal,
ACK, observation journal and actual instrumentation finish. Ordinary package
paths, APK hashes and models, plus the isolated aliases and six private models,
are checked before and after collection. All transport uses the adapted FILE
callbacks and their frozen guard. The root must be the actual adapted FILE OUT.

Local invalid proof or stale output fails before transport and writes. An
operational BaseException records a false outcome once, preserves raw evidence
already written, and rethrows the same primary object. A secondary journal
BaseException is added as a note. Once final outcome publication starts, errors
propagate without rewriting or retrying. A failed terminal can be observed;
quality, true peak and native-policy-effect acceptance always remain false.
