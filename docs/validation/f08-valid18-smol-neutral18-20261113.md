- 原37份、新36份完整49,280维float32向量（均含EOS）各自父验收通过，生成token、全层offset、EOS、原文及严格评分一致。配对首步向量18/18不相同；最大绝对差逐题范围0.89453125–5.796875，RMS范围0.14991–0.85792，softmax总变差范围0.01668–0.77399。
- 不能以13题选项相同推断视觉没有接入。反过来，向量不同也不证明视觉编码正确或输出有正确视觉依据；本轮未重放同输入估计运行间数值噪声，不对差异作唯一内部机制归因。
- 原runner的`labelLogits`取独立`A/B/C` token49/50/51；实际首token为带前导空格的` A/ B/ C`，对应330/389/340。`parent-emitted-choice-verification.json`对两臂全部首向量重新核argmax并decode，真实首选项变化5题。`parent-paired-analysis.json`中的`topABCChanged=2`只指原独立标签token子集，**不是**真实选项变化数或完整答案概率；严格评分始终以完整raw输出为准，未改runner或旧报告。
- 中性图像是分布外干预，不是自然视频benchmark或完整text-only消融；视觉编码器、8帧位置/时间token和问题/选项仍在。50%不能等同“随机猜”，也不能证明训练泄漏、记忆某题、完全忽略视觉或模型容量是唯一原因。
- valid18为小型选定集，非总体显著性结论或训练去污染证明。memory3/3在两臂相同，提示需要能区别文本先验与真实视觉依据的验收；不能据此宣布记忆能力通过。
- 这次是Mac宿主对照，MLX峰值2,608,255,518B约2.43GiB，非iPhone进程物理内存或产品预算。未执行手机验收。
