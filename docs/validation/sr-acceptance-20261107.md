## 新分解结果与含义

使用已验收的 GRAY8 原始逐帧报告推导，不重跑工具测试或原 PSNR/SSIM。令 `e_t = candidate_t - reference_t`，恒等式 `MSE(e_t) = mean(e_t)^2 + MSE(e_t - mean(e_t))`。同尺寸逐帧计算后按像素等权汇总。时域将 `e_t` 换成 `e_t-e_(t-1)`。数值一致性检查仅限制浮点舍入，不是质量门槛；未实际修改或校正任何输出。

| 项目 | SR | bicubic |
| --- | ---: | ---: |
| 原空间 RMSE | 5.160681 | 4.055045 |
| 每帧平均残差贡献的空间 MSE 比例 | 79.2143% | 0.08095% |
| 去每帧平均残差后的空间 RMSE（仅诊断） | 2.352821 | 4.053403 |
| 原时域残差 RMSE | 2.239192 | 1.194275 |
| 每区间平均残差贡献的时域 MSE 比例 | 0.9685% | 0.03984% |
| 去区间平均残差后的时域 RMSE（仅诊断） | 2.228322 | 1.194037 |

SR 每帧平均残差均为负，范围 -5.116288 至 -2.565393（full-range GRAY8 级）。去均值后空间 RMSE 的排序会反转，而局部时域残差仍高于 bicubic。这说明总保真度排序不能直接解释为全部局部细节更差，也不能用“全局偏暗”解释全部时域差异。两者都不是修改亮度、认定传递函数错误、或宣布 SR 通过的依据。

本次实际生成并读取 16 张图：每表连续六帧、列顺序 reference/SR/bicubic。全画面表缩至 320×180 仅查结构；裁剪表每个区域保留 640×360 原像素。工具以 original 细节请求读取，显示界面仍可能缩放。静态视觉观察没有把少数像素的模糊/形状变化写成重复帧、光流失配或可感知闪烁。
