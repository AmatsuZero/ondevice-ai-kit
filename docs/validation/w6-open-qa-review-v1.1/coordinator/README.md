# W6 v1.1 人工回卷对照

收到两位评阅者的正式 JSON 后，在本目录运行以下命令。输出保留独立评分、得分依据和分歧项。

```sh
python3 compare.py "/路径/第一份评分.json" "/路径/第二份评分.json"
```

`agreement.point` 给出 96 个评分要点的一致数，`agreement.veto` 给出 48 份回答的关键反例判定一致数，`agreement.effective` 给出 48 份回答的最终得分一致数。两人可能给出同样的总分，但认可了不同的要点。逐条核对 `disputes` 内的原始引文和原片，另记裁定并保留原判。

本目录含模型对照键。组织盲评时，向两位评阅者提供已准备好的空白表和本机原片。

两份独立评分封存后，可与[原实验结果](../../w6-video-open-qa-v1.1.md)对照。
