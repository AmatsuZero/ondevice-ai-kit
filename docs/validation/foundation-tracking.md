## Updating progress

- Update the matching issue on both platforms when an F item changes state;
  avoid adding duplicate issues for individual sub-items.
- Keep the issue open while any full exit criterion remains unverified. Note
  newly completed sub-items without closing the parent issue.
- Update this repository's validation document with evidence before closing the
  remote issue. Close the issue only after the linked exit criteria pass; the
  platform will then show its milestone as complete.
- No due dates, assignees, or automatic cross-platform synchronization are set.
