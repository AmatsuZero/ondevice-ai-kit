## P1–P4 生产发布证据

| ID | 必须证明的边界 | 充分证据的验收条件 | 当前缺口 |
| --- | --- | --- | --- |
| P1 源码、构建与运行时对应 | 固定实际采用的 runtime/AAR、全部交付 ABI 和运行时成员；逐成员关联实际源码 revision、补丁、构建输入/配置及构建输出 | 可复核的来源链把上述输入和输出绑定到实际 AAR 成员及最终采用的二进制摘要；逐项说明覆盖和差异，不留未解释的运行时成员。可以组合上游构建记录、工件记录、成员核对或同输入重建等证据；任何方法均须接受覆盖与可信度复审 | 四 ORT 成员/日志及[CI 整 AAR、四 ABI/16 库字节对应](w3-sherpa-ci-members-20261115.md)已核；[21 成员/九输入组矩阵、实际补丁及既有隔离消费者绑定](w3-p1-member-matrix-20261115.md)增量已接受。[当前 SDK 本地发布与独立消费者绑定](w3-sdk-consumer-binding-20261115.md)已父验，独立复核因429待恢复；[JVM链接解析到真实源码](w3-jvm-source-resolution-20261115.md)补齐22源字节及声明集合，旧链接blob历史保留；最终生产App采用及逐输入组完整性/可信度接受仍缺，类名/SourceFile不证明字节码等价，P1保持open |
| P2 递归最终组成 | 固定交付物中的直接、静态嵌入及传递组件；覆盖实际版本/源码、补丁、适用许可、声明和归属 | 逐层关联最终二进制成员与其嵌入组件，清单与构建/链接材料相互核对；未纳入、可选或未启用项有依据，不能把源码仓库的依赖声明直接当实际链接组成 | [simple-sentencepiece三文件上游Android补丁、四ABI构建观察及Darts嵌套声明](w3-sentencepiece-patch-20261115.md)已补核；现有归档、源码和构建文本仍不是完整递归最终组成清单，历史CI补丁后源码及最终保留机器码未直接取得，未覆盖项保持显式缺口 |
| P3 实际交付物通知保留 | 固定生产候选的 AAR/SDK/App 及其实际打包、消费链 | 从真实候选交付物提取适用许可/通知并与 P2 清单逐项核对；记录原文、路径及内容摘要，验证消费/打包后仍按适用要求保留，记录所需修改说明与归属 | 本地 141 文件复审包证明材料字节保留，不证明生产 AAR/App 已携带通知；实际生产集成/通知未验 |
| P4 独立发布复审 | 同一固定生产候选、P1–P3 证据及适用再分发条件 | 独立复审明确候选身份、审阅材料、覆盖限制、问题处置及接受结论；未解决的发布问题不能由实现者自报或局部技术复核关闭 | 当前没有该完整发布接受记录；限定源码审查、hy3 日志审阅和本次范围复核均不能替代 |

这里规定证据要达到的结果，**不指定唯一的“加密证明”构造**。摘要用于固定字节身份，本身不证明源码真实性、完整组成或许可满足。选择何种证据方法，要解释实际覆盖及未覆盖部分；现有局部证据不因组合数量增加而自动变为完整证明。
