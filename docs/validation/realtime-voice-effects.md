# 本机实时变声 Demo · 2026-11-27

普通 iOS / Android Demo 的「探索 → 离线变声」默认打开文件模式。切到「实时变声」，选择大叔、少女或播音员，按住按钮监听，松手停止。首次同意麦克风后需要重新按住。实时不保存录音；现有文件 A/B/C、升降调、导入、录音和导出保留。预览构建的包名是 `io.ondeviceai.demo.livepreview`，可与普通 Demo 共存。

耳机和内置扬声器均由平台管理路由。iOS 外放使用 VoiceProcessingIO；Android 外放核对通信设备、录音会话 AEC 和当前播放路由。无法确认时停止，实时路径不退回直通。未知外设与蓝牙兼容性仍需逐设备检查。

**未测**：两端真人耳机出声、实际拔插、中断、60 秒外放回授、外部同钟测量的耳返 P50/P95、三角色盲听。未将软件测试计作 ≤50 ms 或听感达标。
