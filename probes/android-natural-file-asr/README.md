# Public file ASR / resource-window runner

`NaturalAsrInstrumentation.kt` is the accepted test-only runner for the existing
isolated `io.ondeviceai.acceptance.naturalasr` harness. It uses the production
Sherpa ASR primitives and the three existing public LibriSpeech clips, split
into four bounded requests. It does not record the microphone.

The default path retains the accepted natural-file ASR behavior. Optional
instrumentation argument `resourceWindow=true` adds a five-second bind window
before model work and a separately measured ten-second hold after each successful
request. The existing external explicit-PID observer can attach during this
workload. Per-segment duration excludes holds; row duration is wall-clock time
and explicitly discloses possible observation idle. No resource metric is
generated by the runner itself.

The caller supplies a fresh runId, current source fingerprint, installed main APK
digest and the three input digests. These are caller provenance claims; actual
source/APK/input identity is verified by the parent. Reusing a runId is rejected.
The parent builds, reserves one invocation, observes, collects the durable
terminal and restores only its disposable alias. Do not replay a request because
ADB stdout failed; first inspect the same runId and process.

Accepted emulator evidence and the unaccepted physical freezer attempt are in
`docs/validation/w8-asr-window-accepted-20261109.md`. This runner does not establish
physical GPU, energy, peak memory, continuous inference, or resource budgets.
